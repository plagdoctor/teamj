수치형 변수 기초통계 (평균·중위값·이상치 수)

05_numeric_stats.py
▼

이 파일은 무엇을 하나요?

숫자로 된 변수(Speed_Limit, Driver_Age 등)에 대해 최소값, 평균, 중위값, 최대값, 표준편차, 왜곡도, IQR 기반 이상치 수를 계산합니다.

Python 
from scipy import stats

for col in num_cols:
    data = df[col].dropna()
    Q1 = data.quantile(0.25)   # 25% 지점
    Q3 = data.quantile(0.75)   # 75% 지점
    IQR = Q3 - Q1               # 사분위 범위
    lower = Q1 - 1.5 * IQR     # 이상치 하한
    upper = Q3 + 1.5 * IQR     # 이상치 상한
    outliers = ((data < lower) | (data > upper)).sum()

핵심 개념: IQR 이상치 탐지

IQR(사분위 범위) = 상위 25%값 - 하위 25%값. 이 범위의 1.5배를 벗어나는 값은 "이상치"로 봅니다. 예: Speed_Limit에서 29건의 이상치(최대 300)가 탐지되었습니다.

08

전처리 1단계 — 결측치(빈 값) 처리

08_step1_missing_values.py
▼

이 파일은 무엇을 하나요?

비어있는 70개의 값(Weather 30건, Traffic_Density 30건, Driver_Experience 10건)을 적절한 대체값으로 채웁니다.

Python 
# Weather(범주형) → 가장 많이 나오는 값(최빈값)으로 대체
df['Weather'].fillna(df['Weather'].mode()[0], inplace=True)

# Traffic_Density(수치형) → 중위값으로 대체
df['Traffic_Density'].fillna(df['Traffic_Density'].median(), inplace=True)

# Driver_Experience(수치형) → 중위값으로 대체
df['Driver_Experience'].fillna(df['Driver_Experience'].median(), inplace=True)

왜 최빈값/중위값을 사용하나요?

최빈값(Mode): 범주형 변수에서 가장 흔한 값으로 대체 (Weather → "Clear"). 중위값(Median): 수치형 변수에서 극단값의 영향을 받지 않는 중간값으로 대체. 평균(Mean)보다 이상치에 강건합니다.

09

전처리 2단계 — 이상치(극단값) 처리

09_step2_outliers.py
▼

이 파일은 무엇을 하나요?

비현실적인 극단값을 합리적 범위로 잘라냅니다(클리핑). Speed_Limit 300 → 110, Driver_Age 5세 → 18세.

Python 
# Speed_Limit: IQR 상한(110) 초과 → 110으로 제한
Q1 = df['Speed_Limit'].quantile(0.25)
Q3 = df['Speed_Limit'].quantile(0.75)
upper = Q3 + 1.5 * (Q3 - Q1)  # = 110
df['Speed_Limit'] = df['Speed_Limit'].clip(upper=upper)

# Driver_Age: 18세 미만 → 18세로 제한 (도메인 규칙)
df['Driver_Age'] = df['Driver_Age'].clip(lower=18)

핵심 개념: clip() = 클리핑

clip()은 "잘라내기"입니다. 예를 들어 clip(upper=110)은 110을 넘는 모든 값을 110으로 바꿉니다. 데이터를 삭제하지 않고 합리적 범위 안으로 끌어오는 방법입니다.

변수 간 상관관계 분석 (Pearson + Chi-Square + Cramer's V)

14_correlation_analysis.py
▼

이 파일은 무엇을 하나요?

모든 변수와 타겟(사고 심각도) 사이의 관계 강도를 측정합니다. 수치형은 피어슨 상관계수(r), 범주형은 카이제곱 검정 + Cramer's V를 사용합니다.

Python 
# 수치형: 피어슨 상관계수 행렬
corr_matrix = df[num_cols].corr()

# 범주형: 카이제곱 검정 + Cramer's V
for col in cat_cols:
    ct = pd.crosstab(df[col], df['Accident_Severity'])
    chi2, pval, dof, _ = stats.chi2_contingency(ct)
    n = ct.sum().sum()
    cramers_v = np.sqrt(chi2 / (n * (min(ct.shape) - 1)))

핵심 개념 3가지

① 피어슨 상관계수 (r): 두 숫자 변수 사이의 직선 관계. -1~+1 범위. 0에 가까울수록 무관계.
② 카이제곱 검정: 범주형 변수 2개가 "독립인가?" 검증. p값이 0.05 미만이면 연관 있음.
③ Cramer's V: 범주형 연관 강도. 0~1 범위. 높을수록 강한 관계.

핵심 발견

사고 심각도 Top 4 변수: Road_Condition(V=0.57) > Weather(V=0.55) > Traffic_Density(r=0.44) > Speed_Limit(r=0.25)
다중공선성 발견: Driver_Age × Driver_Experience 상관 r=0.9453 (거의 같은 정보)

주요 용어 사전

용어쉬운 설명
DataFrame (df)엑셀 시트와 같은 표 형태 데이터. 행=사고 건수, 열=변수
결측치 (Missing Value)비어있는 셀. 측정 실패, 입력 누락 등으로 발생
이상치 (Outlier)비정상적으로 크거나 작은 값. 예: 속도 제한 300km/h
IQR (사분위 범위)데이터의 중간 50%가 차지하는 범위. 이상치 기준선으로 사용
Pearson 상관계수 (r)두 숫자 변수의 직선 관계 강도. 1=완전 비례, -1=완전 반비례, 0=무관
Cramer's V범주형 변수 간 연관 강도. 0~1. 높을수록 강한 관련
카이제곱 검정"이 두 변수는 서로 관련 있는가?" 통계적으로 검증하는 방법
클리핑 (Clipping)극단값을 합리적 범위로 잘라내기. 데이터를 삭제하지 않고 보정
다중공선성두 변수가 거의 같은 정보를 담고 있는 상태. 모델에 둘 다 넣으면 문제 발생
PdfPagesmatplotlib에서 여러 그래프를 한 PDF 파일에 페이지별로 저장하는 도구
