이해관계자별 핵심 가치 교환 (Value Exchange)

🧒

자녀 (Customer / Payer)

제공: 월 구독료 (4,900~9,900원)
수취: 주간·월간 안전 리포트, 실시간 위험 알림, 가족 대화 가이드, 보험료 할인

👴

부모 (Customer / User)

제공: 운전 데이터 (자동·무의식 수집)
수취: Zero-Touch 안전 관리, 자존심 보호, 보험료 할인, 면허반납 인센티브

🏦

보험사 (Partner / B2B)

제공: B2B 제휴 수수료, 보험료 할인 혜택
수취: 고령 운전자 UBI 데이터 API → 보험 리스크 스코어링 고도화

🏛️

지자체 (Partner / B2G)

제공: B2G 바우처 비용, 면허반납 인센티브
수취: 면허반납 행정 디지털화, 지역별 위험도 분석 대시보드

☁️

AWS 클라우드 (Supplier)

제공: 클라우드 인프라 (SageMaker, TimescaleDB, Kafka)
수취: 인프라 사용 비용

💬

카카오톡 / 지도 API (Supplier)

제공: 알림 전송 API, 도로 제한속도 정보
수취: API 사용료 / 라이선스 비용
